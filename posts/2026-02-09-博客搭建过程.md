# 静态博客搭建完整指南：从零开始构建无编译Markdown博客

## 前言

本文将详细介绍如何搭建一个无编译、基于GitHub Pages的静态博客系统。这种方案结合了静态文件的简洁性与Markdown的易用性，实现"git push即发布"的高效工作流。

## 项目架构概述

这个博客系统采用了极简的无编译架构：

- **前端渲染**：浏览器端使用Marked.js解析Markdown
- **静态文件**：纯HTML/CSS/JavaScript，无需构建工具
- **内容管理**：Markdown文件 + JSON索引
- **部署方式**：GitHub Pages自动发布

## 项目文件结构

```
.
├── index.html              # 主页面
├── .nojekyll              # GitHub Pages配置文件
├── .gitignore             # Git忽略配置
├── CNAME                  # 自定义域名
├── assets/                # 静态资源
│   ├── app.js             # 核心JavaScript逻辑
│   └── style.css          # 样式文件
└── posts/                 # 文章目录
    ├── index.json         # 文章索引
    └── *.md               # Markdown文章文件
```

## 核心文件解析

### 1. index.html - 页面结构

主页面采用响应式设计，包含以下核心组件：
- **顶部导航栏**：品牌标识、导航链接、搜索框、主题切换
- **侧边栏**：个人资料、标签云、外链信息
- **内容区**：文章列表、单篇文章、关于页面
- **底部**：版权信息

### 2. assets/app.js - 动态功能

JavaScript文件提供了以下功能：
- **路由系统**：基于hash的单页应用路由
- **文章加载**：异步获取并解析Markdown文件
- **搜索功能**：实时过滤文章标题、标签、摘要
- **标签系统**：标签云展示与筛选功能
- **主题切换**：支持亮/暗色模式

### 3. assets/style.css - 样式设计

CSS文件采用现代设计风格：
- **主题系统**：支持亮/暗色主题切换
- **响应式布局**：适配桌面和移动设备
- **组件样式**：卡片、按钮、导航等UI组件
- **Markdown渲染**：代码块、引用块等预览样式

### 4. posts/ - 文章管理

文章目录包含：
- **Markdown文件**：每篇文章一个.md文件
- **index.json**：文章元数据索引文件

## 搭建步骤详解

### 步骤1：创建GitHub仓库

1. 在GitHub上创建一个新的仓库
2. 启用GitHub Pages功能（Settings → Pages）
3. 选择分支（通常是main）和目录（/root或/docs）

### 步骤2：初始化项目结构

```bash
mkdir your-blog-name
cd your-blog-name
git init
```

### 步骤3：创建核心HTML文件

创建`index.html`文件，包含基本的HTML结构、CSS和JavaScript引用：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width,initial-scale=1" />
  <title>你的博客标题</title>
  <link rel="stylesheet" href="./assets/style.css" />
  <script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js"></script>
</head>
<body>
  <!-- 页面内容 -->
  <script src="./assets/app.js"></script>
</body>
</html>
```

### 步骤4：编写样式文件

创建`assets/style.css`，包含主题变量、页面布局和组件样式。

### 步骤5：开发核心功能

创建`assets/app.js`，实现：
- 路由系统
- 文章加载与渲染
- 搜索功能
- 标签系统

### 步骤6：配置文章目录

1. 创建`posts/`目录
2. 创建`posts/index.json`文件，格式如下：
```json
[
  {
    "file": "2026-02-09-hello.md",
    "title": "Hello, GitHub Pages",
    "date": "2026-02-09",
    "tags": ["blog", "markdown"],
    "summary": "纯静态 + Markdown，无需编译。"
  }
]
```

### 步骤7：添加第一篇文章

在`posts/`目录下创建Markdown文件，如`2026-02-09-hello.md`。

### 步骤8：配置GitHub Pages特性

1. 创建`.nojekyll`文件，允许使用下划线开头的文件夹
2. 创建`.gitignore`文件，忽略不必要的文件
3. 如需自定义域名，创建`CNAME`文件

## 功能特性

### 1. 路由系统
- `#/` - 文章列表页
- `#/post/<file>` - 单篇文章页
- `#/tag/<tag>` - 标签筛选页
- `#/about` - 关于页面

### 2. 搜索功能
- 支持关键词搜索标题、标签、摘要
- 实时过滤功能
- 快捷键支持（Cmd/Ctrl+K聚焦搜索）

### 3. 主题切换
- 亮/暗色模式自动切换
- 手动切换功能
- 本地存储用户偏好

### 4. 响应式设计
- 桌面端双栏布局
- 移动端单栏布局
- 自适应屏幕尺寸

## 工作流程

### 写作流程
1. 在`posts/`目录下创建新的Markdown文件
2. 更新`posts/index.json`文件，添加文章元数据
3. 提交并推送代码：`git add . && git commit -m "Add new post" && git push`

### 维护流程
1. 修改样式：编辑`assets/style.css`
2. 添加功能：编辑`assets/app.js`
3. 更新内容：修改相应文件后git push

## 总结

这个无编译博客系统提供了一种轻量级、高效的博客搭建方案。通过极简的架构设计，既保证了良好的用户体验，又大大降低了维护成本。对于希望专注于写作而非技术维护的博主来说，这是一个理想的选择。

通过简单的git操作即可完成文章发布，结合GitHub的版本控制功能，还能轻松管理文章的历史版本。这个系统展示了现代Web技术在极简化架构下的强大能力，是静态网站生成器之外的一个优秀选择。
